# 支持状态

从 1.2.0 起，11 个已接入型号使用同一个正式 APK，不再按机型安装测试包。

- **稳定**：已有功能完成过持续实机回归。
- **扩展功能待复测**：基础能力已有测试反馈，本次新增控制仍需对应机型完整回归。
- **基础支持待复测**：识别、电量或核心协议已经接入，但尚未完成一轮完整实机验证。

## 使用边界

- 系统蓝牙页、连接弹窗、超级岛和融合设备中心会按机型隐藏不适用的控制；具体样式仍会受到 HyperOS 和系统组件版本影响。
- FreeBuds 6i 与 FreeClip 2 内置专属图片，其他机型在没有自定义图片时使用通用默认图。
- 手势和 FreeClip 2 扩展设置目前以写入指令和本地记录为主，重新安装、在官方 App 修改设置或切换设备后，界面显示可能需要重新选择。
- FreeBuds 5、FreeBuds Pro 4 与 FreeBuds 7i 暂无已验证的降噪状态回读，首次打开页面时显示的状态可能与耳机当前状态不同。
- 耳机被改名后可在 HuaweiPods 中按蓝牙地址手动选择真实型号，控制协议不会仅凭自定义名称跨型号复用。
